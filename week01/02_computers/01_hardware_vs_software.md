# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
---
Hardware means all the physical components that make up a computer system. These are the parts you can touch, such as the screen, keyboard, mouse, speakers, CPU, memory, and storage devices. Hardware is important because it allows a computer to receive input, process information, store data, and produce output. Without hardware, software would not have anything to run on.


## Explain Software
Write **at least 50 words** explaining what software is.
---
Software is the non-physical part of a computer system that controls how the hardware works. It is made up of code and instructions written by programmers. Software can help people communicate, learn, create, calculate, and solve problems. For example, a music app lets users play songs, while an operating system helps manage files, memory, and devices. Hardware provides the machine, but software gives it purpose.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.
Hardware and software interact by working together to make a computer useful. Hardware is the physical equipment, while software gives instructions to that equipment. For example, when you type on a keyboard, the hardware sends signals to the computer, and the software processes those signals so letters appear on the screen. Software also tells the processor, memory, storage, and other hardware parts what tasks to perform. Without software, hardware cannot do much, and without hardware, software has nothing to run on.
